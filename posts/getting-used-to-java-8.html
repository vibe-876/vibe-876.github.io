What is This Mysterious "Inheritance"?

Within an Object Oriented (OO) language, inheritance refers to a class that gets properties (methods and variables) from another class. For example, we can have the following classes:

public class Animal {
    private int age;
    private String name;

    public int getAge() {
        return(this.age);
    }

    public String getName() {
        return(this.name);
    }

    public void setName(String name) {
        this.name = name;
    }

    public void getOlder() {
        this.age = this.age + 1;
    }
}
public class Chicken extends Animal {
    public Chicken(String chickensName) {
        this.setAge(0);
        this.setName(chickensName);
    }

    public void peck() {
        /* Pecks something */
    }
}

Chicken has inherited all the methods and variables from Animal, so we could do something like this.

public class Main {
    public static void main(String[] args) {
        Chicken myChicken = new Chicken("Bishop");
        System.out.println("My chicken is called " + myChicken.getName() + ".");
    }
}

Now, run the classic javac Animal.java Chicken.java Main.java, and then java Main.
